# Complete Frontend Redesign — Production Plan

## Backend Audit Summary

### All User-Facing Endpoints (17 total)
- Auth: register, login, logout, me, change-password, forgot-password, reset-password, verify-email, resend-verification
- Packages: GET all, GET by slug (returns related packages)
- Blogs: GET all (paginated, searchable by text, filterable by category/tag), GET by slug (increments views)
- Enquiries: POST create, GET my enquiries, GET by id
- Contact: POST create

### Backend Does NOT Have
- No booking/payment system (enquiry-based only)
- No wishlist/favorites
- No reviews submission (rating field exists but no review model)
- No notifications
- No user image upload
- No server-side package search/filters (returns all, client-side filter)

### Models
- **TourPackage**: title, slug, description, category (5 types), destination, duration, price, discountPrice, rating, reviewsCount, highlights[], included[], excluded[], itinerary[], images[], faq[], featured, maxGroupSize
- **User**: name, email, phone, password, role, isVerified, avatar
- **Enquiry**: enquiryNumber, user, tourPackage, travelDate, adults, children, notes, leadStatus (6 states), leadSource, priority
- **Blog**: title, slug, content, excerpt, featuredImage, category (6 types), tags[], author, status, views, seo
- **ContactRequest**: name, email, phone, subject, message, status, source
